# Daily Crit

A Duolingo-style daily edition for design-entrance prep (CEED / NID). Android only.

[**⬇ Download DailyCrit.apk**](https://github.com/divakardznsyk/daily-crit/releases/download/latest/DailyCrit.apk)

Open the link on your phone, install the file (allow installs from your browser if asked), done. Every push to `main` rebuilds the same link.

## What's inside

- **Front page:** fresh design headlines (open in your browser) plus a classics shelf
- **Crit cards:** four design GK questions a day
- **Art desk:** "who made this?" with public-domain paintings (Art Institute of Chicago), offline fallback questions
- **Puzzle page:** odd-one-out, next-in-line and rotation puzzles, drawn live
- **Maths corner:** five quick questions, harder as you level up
- **Studio:** a daily drawing prompt, timer, optional photo log, self-rating
- **PYQ desk:** one-tap links to past papers and your mock-test site, with a right/wrong log
- **Reset:** one-tap path to clear Instagram's storage at night, plus a bedtime reminder

Finish 4 of 7 sections to keep your streak, all 7 for a bonus. Every 200 XP is a level.

Mascot: **Crit**, an eraser who rubs out excuses.

## Build

GitHub Actions builds the APK on every push (see `.github/workflows/build.yml`).
